# Listes des commandes git

## git init 
- Permet d'initialiser un repertoire comme un dépot git

## git add
- Permet d'ajouter un fichier ou des modifications dans le stagging

## git commit
- Permet d'enregistrer des modifications locales
- Le message est important

## git push
- Permet de pousser les modifications locales en ligne

## git status
- Permet de vérifier le status du repertoire
- Permet de lister les modifications à traiter

## git log
- Permet de voir l'historique des modifications en local

## git branch
- Permet de lister les branches en local et distante

## git checkout
- Permet de changer de branche

## git pull
- Permet de récupérer des modifications distantes
