# Listes des commandes git

## git init 
- Permet d'initialiser un répertoire comme un dépot git

## git add 
- Permet d'ajouter un fichier ou des modifications dans le stagging

## git commit
- Permet d'enregistrer des modifications locales
- Le message est important

## git push
- Permet de pousser les modifications locales en ligne

## git status
- Permet de vérifier le status du repertoire
- Permet de lister les modifications à traiter

## git log
- Permet de voir l'historique des modifications en local

## git branch
- Permet de lister les branches en local et distante

## git checkout
- Permet de passer d'une branche à une autre

## git pull
- Permet de récuperer une modification distante

## git rebase (ESC : wq)
- Permet de récupérer des données du main vers la branche secondaire

## git merge
- Permet de récupérer des données de la branche secondaire vers le main

## git reset 
- Permet de supprimer un commit (ou de revenir à un commit définit par son identifiant)

## git diff
- Permet de comparer deux commits

## git clone
- Permet de récuperer un projet distant en local
